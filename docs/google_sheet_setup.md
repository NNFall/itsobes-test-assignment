# Создание Google Таблицы для задачи 3

## Шаги

1. Открыть Google Sheets и создать новую таблицу.
2. Назвать таблицу, например `IT Test Task - CBR Rates`.
3. Открыть `Расширения -> Apps Script`.
4. Вставить код из файла `task3_apps_script/Code.gs`.
5. В настройках проекта убедиться, что часовой пояс `Europe/Samara` или нужный локальный часовой пояс.
6. Сохранить проект.
7. Вернуться в таблицу и перезагрузить страницу.
8. В меню `Курсы ЦБ` выбрать `Обновить курсы`.
9. Подтвердить разрешения Google Apps Script.
10. Проверить, что появился лист `Rates`, а в `I2` записан статус `OK`.
11. Через `Файл -> Поделиться -> Опубликовать/Открыть доступ` выдать доступ на просмотр по ссылке.
12. Вставить ссылку в `docs/final_submission.md`.

## Где смотреть результат

- Лист: `Rates`.
- Статус обновления: ячейка `I2`.
- Заголовки таблицы: строка 5.
- Данные курсов: начиная со строки 6.

## Триггер

Для регулярного запуска нужно открыть меню `Курсы ЦБ` и выбрать `Создать ежедневный триггер`. Скрипт удалит старый триггер для `refreshCbrRates`, если он уже был, и создаст новый ежедневный запуск примерно в 09:00.
