# Задача 3. Apps Script + внешний API в Google Таблице

Apps Script получает курсы валют ЦБ РФ из публичного JSON API `https://www.cbr-xml-daily.ru/daily_json.js`, обрабатывает данные и записывает их в лист `Rates`.

## Что делает скрипт

- Добавляет меню `Курсы ЦБ` при открытии таблицы.
- По пункту `Обновить курсы` запускает функцию `refreshCbrRates`.
- Получает JSON через `UrlFetchApp.fetch`.
- Парсит объект `Valute`.
- Считает курс за 1 единицу валюты, абсолютное и процентное изменение.
- Сортирует валюты по модулю процентного изменения.
- Записывает результат в структурированную таблицу.
- Пишет статус или ошибку в ячейку `I2`.

## Как подключить

1. Создать Google Таблицу.
2. Открыть `Расширения -> Apps Script`.
3. Вставить код из `Code.gs`.
4. При необходимости заменить манифест на содержимое `appsscript.json`.
5. Сохранить проект и перезагрузить таблицу.
6. В меню `Курсы ЦБ` выбрать `Обновить курсы`.

## Триггер

Используется меню в таблице и дополнительный time-based триггер.

Функция `onOpen` создает пользовательское меню. Функция `createDailyRatesTrigger` создает ежедневный запуск `refreshCbrRates` примерно в 09:00 по часовому поясу проекта.
