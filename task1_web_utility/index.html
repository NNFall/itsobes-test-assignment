Веб-утилита для IT-специалиста

IP Subnet Helper

Расчёт IPv4-сетей по CIDR и быстрое планирование подсетей по количеству рабочих хостов.

Калькулятор CIDR

Введите IPv4-адрес с префиксом, например 192.168.10.34/24.

Планировщик подсетей

Укажите базовую сеть и требуемые подсети: имя=хосты или просто число хостов с новой строки.
