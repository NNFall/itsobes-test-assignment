# Задача 1. IP Subnet Helper

Небольшая веб-утилита для IT-специалиста: калькулятор IPv4/CIDR и VLSM-планировщик подсетей по требуемому количеству хостов.

## Что умеет

- Проверяет IPv4/CIDR и показывает понятные ошибки валидации.
- Рассчитывает адрес сети, маску, wildcard, broadcast, диапазон хостов и количество доступных адресов.
- Определяет базовый тип адреса: private, public, loopback, multicast и т.д.
- Планирует несколько подсетей внутри базовой сети по списку требований `Имя=количество_хостов`.

## Запуск

Откройте файл `index.html` в браузере.

Через локальный сервер:

```bash
python -m http.server 8080
```

После этого страница будет доступна по адресу `http://localhost:8080`.
