# Описание работы с AI/Claude Code

Для задачи была выбрана практическая веб-утилита для расчета IPv4-подсетей, потому что это близко к работе IT-специалиста и содержит проверяемую бизнес-логику.

Ключевые промпты, которые использовались как рабочие формулировки для Claude Code/AI-ассистента:

1. `Сделай статическую веб-утилиту HTML/CSS/JS для расчета IPv4 CIDR: сеть, маска, wildcard, broadcast, диапазон хостов, количество доступных адресов. Код раздели по файлам.`
2. `Добавь VLSM-планировщик: пользователь вводит базовую сеть и список требований вида Office=120, WiFi=60. Нужно отсортировать требования, подобрать префиксы и вывести таблицу подсетей.`
3. `Проверь пограничные случаи /31 и /32, валидацию IPv4 и человекочитаемые ошибки.`

AI хорошо сгенерировал начальную структуру интерфейса и базовые функции преобразования IP-адресов. Вручную была уточнена логика расчета сетевого адреса через размер блока, чтобы не зависеть от знаковых битовых операций JavaScript. Также вручную доработана обработка ошибок, VLSM-выравнивание подсетей и оформление результата в таблицу. Отдельно проверялись пограничные случаи: неправильный октет, отсутствие префикса, /31 и /32. Финальная версия оставлена без сборщика, чтобы проверяющий мог открыть страницу локально без установки зависимостей.
