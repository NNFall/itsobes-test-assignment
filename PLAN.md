# План действий

## Этап 1. Подготовка структуры

Статус: выполнено.

- Создать отдельные папки под каждую задачу.
- Выбрать общий внешний API для задач 2 и 3.
- Завести общий журнал операций и README.

## Этап 2. Задача 1: веб-утилита

Статус: выполнено.

- Реализовать полноценную страницу HTML/CSS/JS.
- Добавить нетривиальную клиентскую логику.
- Разделить код по файлам.

## Этап 3. Задача 2: Python + API + Docker

Статус: выполнено.

- Написать Python-скрипт с HTTP-запросом к внешнему API.
- Добавить обработку JSON, сортировку и расчет производных значений.
- Добавить базовую обработку ошибок.
- Подготовить `requirements.txt`, `Dockerfile`, пример вывода и README.

## Этап 4. Задача 3: Apps Script

Статус: выполнено на уровне исходного кода.

- Написать `Code.gs`.
- Использовать `UrlFetchApp.fetch`.
- Записать обработанные данные в таблицу.
- Добавить меню и time-based триггер.
- Добавить обработку ошибок в отдельную ячейку.

## Этап 5. Проверка и финальная упаковка

Статус: частично выполнено.

- Проверить Python-скрипт локально.
- Проверить синтаксис JS и Apps Script.

- Создать Google Таблицу и вставить ссылку.
- Подготовить архив или GitHub-репозиторий.
